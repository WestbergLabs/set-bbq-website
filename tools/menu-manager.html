About menu data

Menu changes are stored in Supabase and are available to the public menu and catering order form immediately after saving.

  • data/menu.json and data/prices.json are retained as legacy reference copies only.
  • Changing an item name does not change its ID.
  • Use the arrows to change an item's order within its category.
  • Delete removes the item and its price entry from the database.
  • Options use one row per option with a label and price adjustment.
